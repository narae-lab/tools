검토 기록

사용 안내

보험별 탭을 선택하면 해당 보험의 검토 내역과 건수를 볼 수 있습니다. 인원명부는 공통 자료입니다. 셀 클릭·드래그·Shift+방향키로 선택하고 Ctrl+C로 복사하세요. 셀 값은 직접 편집하지 않습니다.

단축키: Ctrl+↑/↓ 처음·마지막 행, Ctrl+←/→ 처음·마지막 열, Ctrl+Home/End 첫·마지막 셀, Shift를 함께 누르면 범위 선택, Alt+↓ 선택 열 필터, Ctrl+Shift+L 필터 켜기·끄기, Ctrl+F 검색, Ctrl+C 복사, Page Up/Down 100행 이동. Ctrl+방향키는 빈 셀 경계 대신 필터된 전체 결과의 끝으로 이동합니다.

  1. 누적 고지 엑셀을 보험별로 가져옵니다. 건강보험 원본에서 장기요양도 함께 읽습니다.
  2. 인사명부, 월별 지급율적용제외, 기간별 예외지급율관리, 납부유예·재개를 가져옵니다.
  3. 예: 11월 고지 검토에는 10월 변동과 10월 제외자료를 연결합니다. 급여번호는 적용월로 사용하지 않습니다.
  4. 자동 인식 결과와 미리보기를 확인한 뒤 반영합니다. 잘못 인식한 항목은 ‘연결 수정’에서 바꿀 수 있습니다. 고지 파일은 보험 종류별로 교체되고, 월별 제외자료는 지정한 월만 교체됩니다.
  5. 검토 대상에서 ‘기록’을 눌러 메모합니다. 고지자료를 교체해도 기록은 남습니다. 자료 변경 후에는 이전 기록을 재확인하세요.
  6. 작업 종료 시 ‘전체 백업’을 저장하세요. 다른 브라우저·PC 또는 브라우저 데이터 삭제 후에는 백업 복원이 필요합니다.

이 도구는 고지 내역과 회사 관리자료의 대조를 돕습니다. 공단 자격명부가 없으므로 가입 자체의 정상 여부를 확정하지 않습니다. 고지 없음, 정산만 있음, 신청 완료는 서로 다른 상태입니다.

1·2 = 해당 열의 신청 완료 / 불가 = 신청 대상 아님 / 빈칸 = 미기재. 개인별 고지액과 실공제액의 차이는 검사하지 않습니다. 고용·산재에 건강·국민 유예 상태를 적용하지 않습니다.

지원: .xlsx, 일반 셀 값과 저장된 수식 결과. 암호화 파일·.xls·실제 .xlsb는 Excel에서 .xlsx로 저장하세요. 필요 자료가 없으면 정상 0건으로 표시하지 않고 미등록으로 표시합니다.
